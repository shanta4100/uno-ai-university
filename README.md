# uno-ai-university
Official website for UNO AI University - Advanced AI education and research

## About

A modern, responsive static website for UNO AI University, built with plain
HTML5, CSS3, and vanilla JavaScript (no build step or backend required).

**Mission:** Advancing AI education and research for tomorrow's leaders.

**Vision:** Creating world-class AI education accessible to all.

## Running locally

This is a static site with no build tools required. To preview it locally,
serve the directory with any static file server, for example:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser.
